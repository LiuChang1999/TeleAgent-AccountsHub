TeleAgent 账号工作台 v0.7.1（Windows 64 位单文件版）

运行
双击 TeleAgentAccounts.exe 或 TeleAgent-Account-Desk-v0.7.1-win64.exe。
程序已内嵌 Microsoft 签名的 WebView2Loader.dll，无需旁置 DLL，也无需管理员权限。
首次运行自动将内嵌加载库释放到当前用户管理器数据目录中的 runtime 缓存；每次加载前核对内嵌字节，缓存损坏时自动修复。
目标电脑仍需安装 Microsoft Edge WebView2 Runtime，且需安装 TeleAgent 并自行完成账号登录。
运行新版前，请先右键托盘退出旧工作台。默认关闭窗口会收起到托盘；可在设置中心改为退出。

账号目录
程序启动时会自动查找 TeleAgent 的账号数据目录，依次尝试：上次保存的目录、%USERPROFILE%\.local\share\TeleAgent、XDG_DATA_HOME、%APPDATA%\TeleAgent、%LOCALAPPDATA%\TeleAgent、%LOCALAPPDATA%\Programs\TeleAgent、%USERPROFILE%\TeleAgent、%ProgramData%\TeleAgent，以及 TeleAgent.exe 所在目录及其上级目录。
每个候选目录会检查是否包含 users 文件夹或账号标记文件；多个候选都存在时，选择账号数量最多的一个，并自动记住，下次启动优先使用。
设置中心 → 程序与数据 → “重新查找账号目录”可重新执行一次查找；找不到时可用“选择账号目录”手动指定包含 users 文件夹的目录。
账号列表为空时，界面会直接给出“自动查找”和“选择账号目录”两个按钮。
如果 TeleAgent 已安装但从未登录，users 文件夹不存在，此时需要先在 TeleAgent 中完成一次登录。
手动选择的目录按当前 Windows 用户保存在管理器数据目录的 settings.json 中；目录被移动或删除时自动改用其他可用位置。
选中的目录里没有 users 文件夹时会提示，不会写入错误路径。

静默巡检
1. 在“账号工作台”搜索或筛选分组，选择本次巡检范围。默认范围为全部账号。
2. 点击“静默巡检”，确认账号数量后点击“开始巡检”。执行一轮，不会定时循环。
3. 程序逐个保存当前会话、关闭 TeleAgent、切换目标账号并打开，最多等待 40 秒识别启动身份，再检查本地凭据和已知 Cookie 到期情况。
4. 执行过程中不弹提示、不打断使用；界面顶部只显示“静默巡检中”，可随时点击“停止巡检”。
5. 每个账号的结果写入“巡检结果”面板与“操作历史”，包含成功、失败原因和未执行数量。
6. 可恢复的单个账号失败后继续下一个；任务运行、无法关闭或无法保存快照时停止，保留现场。
7. 正常结束后尝试回到开始时的账号。

巡检只复用本人在本机已有的登录资料，不代填密码、验证码，也不会自动完成已失效会话的重新登录。
“已保存”表示启动身份匹配、本地资料检查通过且已写入新快照；本地 Cookie 和启动记录不能单独保证服务端仍接受该会话。以 TeleAgent 实际显示的登录状态为准。
同一账号可能同时存在多个令牌 Cookie，只有全部令牌都过期才会记为失效，避免误报。
巡检结果保存在 %LOCALAPPDATA%\TeleAgentAccountDesk\manager-data\last-poll.json，仅含展示名称、账号 ID、时间、状态和原因，不包含令牌或 Cookie 值。

其他功能
- 搜索账号备注、用户名、ID、缓存手机号；支持分组、星标置顶和仅置顶筛选。
- “操作历史”显示最近 200 条操作，可搜索并按结果筛选。
- “会话备份”支持空间统计、按保留数量预览并清理旧备份。当前快照、最近恢复所需备份、未完成和来源异常资料始终保留。清理后的旧备份无法恢复。
- 右键托盘“切换账号”可快速切换；仍执行任务保护与身份核对。
- “新登录账号”与“重新登录”打开 TeleAgent 登录入口，需要本人手动完成登录。
- “本机退出登录”仅处理本机资料，不请求服务端注销。聊天数据库和配置保留。
- “恢复最近操作”会检查新登录资料，避免覆盖。

管理器数据
按 Windows 用户保存在 %LOCALAPPDATA%\TeleAgentAccountDesk\manager-data。
账号备注、分组、历史、登录快照、操作备份均只保存在本机。
源码目录与可执行文件可移动，管理器数据不会跟随 EXE 复制给其他用户。

分发
可只发送单文件 EXE；WebView2 许可证已内嵌，可在程序底部点击“WebView2 许可证”查看。
也可发送包含 EXE、许可证及本说明的 v0.7.1 分发 ZIP。SHA256SUMS.txt 提供两个分发文件的校验值。
分发包不包含任何实际账号、Cookie、令牌、备注、会话快照或操作备份。

兼容性
账号切换依赖 TeleAgent 内部本地格式，尚非官方接口；升级 TeleAgent 后需重新检查兼容性。

设置中心
- 显示系统托盘图标：关闭后，最小化保留任务栏、关闭窗口退出；依赖托盘的启动隐藏行为会自动取消。
- 关闭窗口时：可选收起到托盘或退出。账号操作进行中会保留程序，完成或停止后才能退出。
- 最小化时收起到托盘、手动启动时收起到托盘：可分别选择。
- 开机自启：默认关闭。保存启用后仅为当前 Windows 用户登记，登录 Windows 后打开工作台，不需要管理员权限。
- 自启时收起到托盘：与手动启动单独设置；关闭托盘后不再隐藏。
- 系统托盘通知：控制巡检失败、完成的 Windows 提示；不影响窗口内结果和历史记录。默认静默，不弹窗口提示。
- 账号自动刷新：可选每 3、5、10、30 秒，或仅手动刷新。启动、手动点击刷新及账号操作后仍会读取。
- 设置修改需点击“保存设置”后生效。“恢复默认”只填回默认选项，仍需保存。
- 程序路径、账号目录和工作台数据目录可在设置中心查看或选择；底部提供“退出工作台”。

自启使用当前 EXE 的完整路径，请先将程序放在固定目录。移动或重命名后，在新位置运行程序并保存设置可更新启动项。
Windows 的“启动应用”设置可能单独禁用该启动项；“已登记”表示工作台已写入启动配置，不代表 Windows 一定允许执行。
关闭开机自启并保存后，仅移除工作台自己的启动项，不影响其他程序。
窗口与后台设置保存在管理器数据目录中的 desktop-settings.json，不会覆盖 TeleAgent 程序路径与账号目录设置。
