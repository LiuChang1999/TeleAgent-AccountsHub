v0.7.1 是稳定性与易用性更新，账号数据格式与 v0.7.0 完全兼容，可直接覆盖升级。

- **修复“无法获取登录数据”**：账号扫描不再因为单个账号的分区目录或账号指针异常而整表失败。旧版本遗留的重复分区目录只影响该账号并给出提示，其余账号正常显示；账号指针格式无法识别时降级为提示，不再隐藏全部账号。
- **修复“巡检成功却提示登录失败”**：同一账号存在多个令牌 Cookie（例如已过期的 operationToken 与有效的 operToken）时不再误判，只有全部令牌都过期才记为失效。
- **巡检改为静默执行**：执行中不弹提示、不打断使用，结果只写入“巡检结果”与“操作历史”；按钮与文案统一为“静默巡检”。
- **账号目录自动发现**：依次尝试已保存目录、`%USERPROFILE%\.local\share\TeleAgent`、`XDG_DATA_HOME`、`APPDATA`/`LOCALAPPDATA`/`ProgramData` 以及 TeleAgent.exe 所在目录等位置，按账号数量选择最可信的一个并记住。设置中心可“重新查找账号目录”；账号为空时提供“自动查找 / 选择账号目录”两个入口。目录失效时自动回到可用位置。
- **界面精简**：移除统计卡注释、页面说明、账号 ID、Cookie 副标题、设置项说明等小字，保留关键信息与操作。

下载 `TeleAgent-Account-Desk-v0.7.1-win64.exe` 可直接运行；ZIP 另含使用说明和许可证。`SHA256SUMS.txt` 提供两个分发文件的校验值。

运行前请先从托盘退出旧工作台。目标电脑需要安装 TeleAgent 和 WebView2 Runtime。开机自启默认关闭，需在设置中心保存启用。失效登录或验证码仍需本人在 TeleAgent 中处理；本地检查不等同于服务端会话验证。

Windows 64 位 Release 构建已通过核心、安装路径、账号管理、轮询、设置、备份和 WebView2 界面启动回归；本轮新增“重复分区目录只影响单个账号”“账号指针异常不隐藏列表”“过期残留令牌不误判会话失效”三项用例。巡检使用模拟账号验证；启动项写入测试使用隔离注册表项，真实开机启动项未被改变。
